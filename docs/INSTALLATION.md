# Installation Guide

## Prerequisites

Before installing RICR Interview Task, ensure you have the following:

- **Node.js** 16 or higher
- **MongoDB** instance (local or MongoDB Atlas cloud)
- **Cloudinary** account (for image/file uploads)
- **npm** or **yarn** package manager
